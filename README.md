## ✨ Highlights

- **DTAM:** Deformable Texture-Aware Module for high inter-class visual similarity.
- **GLSFN:** Global-Local Scale Fusion Network for extreme scale variation.
- **BSFE:** Background-Suppressing Feature Encoder for complex background interference.
- **Real-time performance:** 119 FPS on an NVIDIA A100 GPU.
- **Detection accuracy:** 62.1% mAP50 and 44.6% mAP50:95 on the Ethnic-16 dataset.
