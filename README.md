# EC-DETR
**EC-DETR: Deformable Perception and Multi-Scale Fusion Transformer for Real-Time Complex Ethnic Costume Detection**

> Submitted to IEEE Transactions on Circuits and Systems for Video Technology (TCSVT)

---

## 🔔 Code Release

The full implementation code will be made publicly available upon acceptance of this manuscript.

**Current status: Under Review** 🔄

---

## 📌 Highlights

- 🧵 **DTAM**: Deformable Texture-Aware Module for high inter-class visual similarity
- 🔍 **GLSFN**: Global-Local Scale Fusion Network for extreme scale variation
- 🛡️ **BSFE**: Background-Suppressing Feature Encoder for complex background interference
- ⚡ **119 FPS** real-time inference on NVIDIA A100
- 📊 **62.1% mAP₅₀** / **44.6% mAP₅₀₋₉₅** on Ethnic-16 dataset
